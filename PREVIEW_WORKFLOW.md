# Mailing Memories Preview Workflow

This branch is the staging/preview workspace for customer-facing website changes.

- Production branch: `main` → https://mailingmemories.com
- Preview branch: `preview`
- Changes should be made and reviewed on `preview` first.
- Only approved changes should be merged or copied to `main`.
- Technical production fixes may still be made directly to `main` when necessary, but customer-facing design/content work should default to `preview`.
