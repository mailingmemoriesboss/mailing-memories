# Staged pricing and showcase consent
User-approved base $15 includes up to 250 inside-message words. Each started additional block of 250 costs $5 and is fulfilled as one mini card included with the main card. The front greeting/signature are excluded from the provisional count. Whitespace-delimited count includes hyphenated words as one. Existing 20,000-character server limit remains; physical envelope thickness/weight for unusually long orders must be evaluated before activation. No standalone mini-card purchase.
Quote is computed in shared code on browser and server. New durable-v2 Stripe sessions retain the base Stripe price and add an inline $5 mini-card line item; DB stores expected subtotal and verifies it against the matching Stripe session, allowing existing promotion codes. durable-v1 existing sessions remain $15 and supported. Before launch verify base Stripe price is still $15, checkout discounts, extra cards fit the envelope, package/postage cost, all public price references and legacy route use, payment retries, and staged schema. No active price changes without those checks.
Optional showcase permission is unchecked, separate from purchase, recorded with version/time, no automatic publishing. Anonymous examples only: remove names, addresses and identifying/private details, no external reuse if not clearly safe. Historical orders default false. Revocation/manual review and privacy cleanup must be verified. Do not use photos from fulfillment as marketing material merely because customer opted into examples.
Certified Mail: USPS current add-on fee $5.55 plus ordinary postage. $5 proposed customer fee is below cost. Recommend $8 surcharge for Certified Mail with tracking (no return receipt), pending owner approval and physical-mail procedure; do not enable or charge in this branch.
